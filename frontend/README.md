# Frontend

React + TypeScript + Vite. See the root [README](../README.md) for setup,
[development guide](../docs/development.md) for configuration and tests, and
[API reference](../docs/api.md) for backend contracts.

Run `npm ci` and `npm run dev` here, with the backend listening on port 8000.
Production builds default to `/course1107/`. Upload all files in dist together;
copying an index file from a different build can produce missing JS/CSS requests.
